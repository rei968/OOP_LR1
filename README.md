# Furniture Catalog Desktop App (JYSK Inventory)

Десктопний застосунок для ведення обліку та каталогізації товарів меблевого магазину, розроблений мовою **C# (Windows Forms / .NET)** відповідно до принципів об'єктно-орієнтованого програмування (ООП).

Проєкт розроблено в рамках лабораторної роботи із застосуванням методології **Gitflow**, трекера завдань **Trello** та системи обліку часу **Toggl Track**.

---

## Стек технологій та інструменти
* **Мова програмування:** C# (.NET)
* **Платформа UI:** Windows Forms
* **Контроль версій:** Git, GitHub
* **Методологія розгалуження:** Gitflow (`main`, `develop`, `feature/*`, `release/*`)
* **Управління завданнями:** Trello (Scrum/Kanban-дошка)
* **Тайм-трекінг:** Toggl Track

---

##  Основний функціонал
* **Каталог меблів:** Перегляд товарів у табличному вигляді (`DataGridView`) з відображенням артикулу, назви, категорії, кольору, ціни, залишку та статусу наявності.
* **CRUD-операції:** Додавання нових одиниць меблів, редагування існуючих записів та видалення.
* **Валідація даних:** Перевірка коректності введення цін, кількості та обов'язкових текстових полів.
* **Фільтрація та пошук:** Швидкий пошук за назвою або категорією, а також фільтрація товарів, що є в наявності.
* **Збереження даних:** Експорт та завантаження каталогу у локальні файли для збереження стану між сесіями.

---

## Структура проєкту
* `InteriorItem.cs` — клас-модель даних меблевого виробу (інкапсуляція, поля, властивості, валідація).
* `FurnitureService.cs` — сервісний шар бізнес-логіки (управління списком об'єктів, CRUD, фільтри, робота з файлами).
* `Form1.cs` / `Form1.Designer.cs` — презентаційний шар (графічний інтерфейс користувача та обробники подій).
* `Program.cs` — точка входу застосунку.
